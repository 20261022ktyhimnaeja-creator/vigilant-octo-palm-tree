# SNS × AI 마케팅 스킬

사용자가 올린 SNS 마케팅 강의 자료(PDF 12종)에서 배운 방법론을 **재구성·요약**한 스킬이다.
원본 자료는 저작권 보호 대상(무단배포 금지)이므로 원문을 그대로 옮기지 않았고, 예시 프롬프트는 모두 새로 작성했다.

## 언제 어떤 참고 파일을 읽을지

| 사용자 요청 | 읽을 파일 |
|---|---|
| 인스타 계정 시작/점검, 프로필·이름·소개글·링크·하이라이트·고정글, 타겟 분석 | `references/instagram-setup.md` |
| 협찬·공구·협업 제안, 제안 메일/DM 작성, 받은 제안 거르기, 단가 제시 | `references/brand-pitching.md` |
| 릴스/쇼츠 초반 이탈 방지, 시청 지속 트릭, 캡컷 편집 | `references/hooking-tricks.md` |
| 마케팅에 쓸 AI 툴 추천 (카피, 요약, 회의록, 이미지, 나레이션, 아바타, 리서치) | `references/ai-tools.md` |
| AI 이미지: 피규어 디오라마, 구름 글씨/캐릭터, 사진 편집 명령, 캔바 템플릿 | `references/ai-image-prompts.md` |
| AI ASMR·바이럴 영상 프롬프트 | `references/asmr-video-prompts.md` |

## 작업 원칙

1. **타겟 먼저.** 어떤 콘텐츠든 "누구를 위한 것인가"를 확인한다. 정보가 없으면 업종·타겟·판매 상품을 짧게 묻거나, 합리적으로 가정하고 가정했다고 밝힌다.
2. **바로 쓸 수 있는 결과물.** 소개글은 4줄 안, DM은 그대로 복사해 보낼 수 있는 완성 문장, 프롬프트는 복사 가능한 코드 블록으로 준다.
3. **이미지/영상 프롬프트는 영어로** 작성하고, 사용자가 바꿀 부분은 `(괄호)`로 표시한 뒤 한국어 설명을 붙인다. 결과가 마음에 들 때까지 수정 요청을 반복하라고 안내한다.
4. **브랜드 로고·상표가 들어가는 이미지**(예: 유명 브랜드 피규어)는 개인 재미용은 괜찮지만, 상업적 광고에 쓰면 상표권 문제가 생길 수 있다고 한 줄로 알려 준다. 실존 인물 사진은 본인 사진이나 동의받은 사진만 쓰도록 안내한다.
5. **과장 금지.** "무조건 바이럴", "수익 보장" 같은 약속은 하지 않는다. 후킹 트릭은 남용하면 신뢰가 떨어질 수 있다고 함께 말해 준다.
6. 툴 UI와 메뉴 이름은 자주 바뀐다. 단계 안내 끝에 "메뉴 이름이 다르면 비슷한 항목을 찾으세요"라고 덧붙인다.
