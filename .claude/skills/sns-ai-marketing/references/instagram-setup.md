# 인스타그램 계정 세팅 (수익화용 "간판 작업")

핵심 아이디어: 처음 들어온 사람이 **3분 안에** "이 계정이 누구이고, 뭘 주고, 왜 팔로우해야 하는지" 알 수 있어야 팔로우와 구매로 이어진다. 내가 하고 싶은 이야기가 아니라 **타겟이 관심 있는 이야기**를 올려야 사람이 모인다.

## 1단계: 사전 점검 질문 (콘텐츠 올리기 전에)

사용자와 함께 아래 질문을 채운다.

1. **타겟은 누구인가?** 나이 / 성별 / 직업 / 소득 수준 / 성향
2. **타겟의 고민 3가지 이상**
   → 내 제품이나 서비스가 풀어 줄 수 있는 고민을 골라 **"해결형" 콘텐츠**로 만든다.
3. **타겟의 관심사 3가지 이상**
   → 판매와 직접 관계없는 **"유입용" 콘텐츠**로 활용한다. 홍보하지 않는 콘텐츠도 꼭 필요하다.
4. **나만의 스토리 / 차별점은?**
   → 소개글과 콘텐츠에서 계속 반복해서 보여 준다.

답이 막히면 타겟이 모여 있는 곳(카페, 단톡방, 상품 후기, 경쟁 계정 댓글)을 직접 둘러보며 그들이 쓰는 말을 수집하라고 권한다.

## 2단계: 프로필 6요소

| 요소 | 체크포인트 |
|---|---|
| **프로필 사진** | 판매를 할 계획이면 얼굴이 보이는 사진이 신뢰를 준다. 상반신이나 얼굴을 크게 넣는다(전신은 너무 작게 보임). 배경은 깔끔하게 정리한다(배경색 바꾸는 웹 툴 활용 가능). |
| **이름 칸** | 인스타 **검색에 걸리는** 칸이다. 키워드 3가지를 넣는다: ① 나를 부르는 이름 ② 브랜드명 ③ 사람들이 많이 검색하는 주제 키워드. 타겟이 한국인이면 한글로 쓴다. |
| **소개글** | 최대 **4줄**까지 쓴다(5번째 줄부터는 "더보기"로 접힘). 넣을 내용: ① 나 또는 브랜드 스토리 ② 이 계정이 주는 정보 ③ 차별점과 강점 ④ 링크 클릭을 유도하는 문구. 같은 업종에서 잘 된 계정 2~3개를 참고해 나만의 톤으로 쓴다. |
| **링크** | 링크 2개를 따로 넣기보다 **멀티 링크 서비스**(리틀리, 링크트리 등) 하나로 모은다. 상담 채널, 홈페이지, 유튜브, 블로그 등을 넣는다. 네이버 링크를 메인에 바로 걸면 열리지 않는 경우가 있으니 멀티 링크로 우회한다. |
| **하이라이트** | 필요한 것만 **최대 5개**. 브랜드 계정은 가격, 예약, 오시는 길, 후기 등을 넣고, 개인 계정은 차별점과 주제 관련 내용을 넣는다. 오래된 내용은 정리해서 최신 상태를 유지한다. |
| **상단 고정 게시물 3개** | ① 계정 주인 스토리와 소개 ② 판매하는 제품이나 서비스 설명 ③ 시즌 혜택이나 중요한 공지 |

## 출력 템플릿

소개글을 요청받으면 이 형식으로 3가지 버전을 준다.

```
[1줄] 누구인지 + 스토리 한 조각
[2줄] 이 계정에서 얻을 수 있는 것
[3줄] 차별점 / 숫자로 된 실적
[4줄] 👇 행동 유도 (상담, 무료 자료, 예약)
```

이름 칸 예시 형식: `홍길동 | 브랜드명 | 홈트 다이어트`
