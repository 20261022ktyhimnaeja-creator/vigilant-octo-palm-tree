# 마케팅에 바로 쓰는 AI 툴 7가지

툴 UI와 요금제는 자주 바뀐다. 추천할 때는 "용도 → 툴 → 쓰는 법 3단계 → 활용 예시" 순으로 짧게 안내한다.

| 용도 | 툴 | 핵심 사용법 | 활용 예시 |
|---|---|---|---|
| 광고 카피·후킹 문구 | **아이작(AISAC)** – 한국방송광고진흥공사의 무료 AI 카피 서비스 | 프로젝트 작성(제품명, 짧고 명확한 서비스 설명, 타겟, 광고 목적) → 카피 유형에서 "후킹/소셜미디어 문구" 선택 → 생성 후 복사하거나 즐겨찾기 | 설명에 강한 키워드("단 3일") 넣기, 타겟을 구체적으로 쓸수록 정밀해짐 → SNS·배너·상세페이지 제목에 활용 |
| 영상 요약 → 숏폼 대본 | **Lilys AI** | 로그인 → 유튜브 URL 붙여넣기 → 전체 요약 / 숏폼 대본 / 핵심 포인트 중 선택 | 긴 강의를 15초 릴스로, 뉴스 영상을 블로그 글로, 자기계발 영상을 인스타 글로 |
| 회의·상담 기록 | **Tiro** | 새 회의 → 실시간 마이크 녹음 또는 줌/구글밋 연동 → 끝나면 요약, 키워드, 할 일이 자동 정리 | 회의록, 고객 상담 기록, 인터뷰 대본, 수업 정리 |
| 이미지 생성 | **Google AI Studio** (Gemini 이미지 모델, "나노바나나") | 새 프롬프트 → 원하는 이미지를 **영어로** 구체적으로 설명(스타일 키워드: minimalist, flat illustration, realistic, pastel tone) | SNS 배경, 블로그·유튜브 썸네일, 전자책 표지 시안 |
| AI 나레이션 | **ElevenLabs** | 텍스트 입력 → 목소리 선택 → 생성 | 릴스 나레이션, 광고 성우 대체 |
| AI 아바타 영상 | **HeyGen** | 아바타 선택(또는 본인 아바타 생성) → 대본 입력 → 생성 | 얼굴 없이 설명 영상, 다국어 영상 |
| 출처 기반 리서치 | **Perplexity** | 질문 입력 → 출처 링크가 달린 요약 답변 → 후속 질문으로 깊게 파고들기 | 콘텐츠 기획 리서치, 툴·전략 비교, 주제 아이디어 뽑기 |

## 추가 툴 지도 (용도별)

| 용도 | 툴 |
|---|---|
| 콘텐츠 아이디어, 대본 | ChatGPT (프롬프트는 `content-prompts.md`) |
| 카피라이팅 | Copy.ai, 아이작 |
| 이미지 생성 | Leonardo AI, Google AI Studio, ChatGPT |
| 디자인 템플릿 | 미리캔버스(한글 템플릿 강점), Canva |
| 로고 시안 | Looka |
| 영상 생성 | Pixverse, Kling, Higgsfield |
| 영상 편집 | CapCut |
| 상세페이지 | 제디터 AI(가비아), Gamma + ChatGPT 카피 |
| 업무 정리 | Notion |
| 워터마크 제거 | Media.io 등. **본인이 권리를 가진 영상**(예: 내 체험판 결과물)에만 쓰도록 안내한다. 남의 콘텐츠 워터마크를 지우는 건 저작권 침해다. |

안내 원칙:
- 목소리나 얼굴 복제는 **본인 또는 동의받은 사람**만 하도록 안내한다.
- 광고에 AI 생성 인물이나 목소리를 쓰면 플랫폼별 AI 표시 규정을 확인하라고 알린다.
