# 챗GPT 콘텐츠 기획 & 상세페이지 프롬프트

모든 프롬프트는 이 스킬을 위해 새로 작성했다. 사용자가 요청하면 프롬프트를 건네주거나, 내가 직접 그 프롬프트대로 결과물을 만들어 준다.

## 1. 숏폼 주제 → 대본 2단계 프롬프트

조회수가 검증된 주제 유형(명언 모음, 다이소·쿠팡·올리브영 제품 리뷰, 생활 꿀팁 등)에 쓴다.

**1단계: 주제 뽑기**
```
조회수가 잘 나오는 숏폼을 만들 거야.
사람들이 실제로 많이 클릭하는 '(콘텐츠 유형: 예) 다이소 꿀템 리뷰)' 주제 10가지를 뽑아줘.
타겟은 (타겟). 각 주제 옆에 왜 클릭할지 한 줄 이유도 붙여줘.
```

**2단계: 고른 주제로 대본 만들기**
```
(번호)번 주제로 20초 내외 숏폼을 만들 거야. 아래를 만들어줘.
1) 스크롤을 멈추게 할 후킹 문구 3가지 버전
2) 화면에 들어갈 자막 대본 (장면별, 예시 포함)
3) 본문 캡션 3가지 (각 300자 이내, 첫 줄에 검색 키워드, 마지막에 저장/댓글 유도)
```
팁: 후킹 원리는 `hooking-tricks.md`, 검색 최적화는 `growth-strategy.md`를 참고해 결과를 다듬는다.

## 2. 상세페이지 카피 프롬프트 (챗GPT → 감마·캔바·제디터 등에 붙여넣기)

```
너는 전환율 높은 상세페이지를 쓰는 브랜드 카피라이터야.
아래 정보로 상세페이지 콘텐츠를 만들어줘.

[제품 정보]
- 제품/서비스명: (이름)
- 핵심 특징 3가지: (특징)
- 주 타겟: (타겟)
- 가격대: (고급 / 중가 / 가성비)
- 경쟁 제품 대비 차별점: (차별점)
- 쓰고 나면 고객에게 생기는 변화: (변화)

[스타일]
- 톤앤매너: (감성적 / 신뢰감 / 발랄 / 트렌디)
- 문체: (존댓말 / 반말 / 설명형 / 스토리텔링)
- 강조할 것: (가격 / 후기 / 디자인 / 효능 / 브랜드 스토리)

[구성]
1. 시선을 끄는 헤드라인 (고객의 구체적인 순간으로 시작)
2. 고객 고민 공감 문구
3. 핵심 특징 3가지 (사양이 아니라 고객이 겪는 변화로)
4. 사용 후 변화와 후기가 들어갈 자리 (예시 후기 문구는 [후기 자리]로 표시)
5. 구매를 부르는 마무리 CTA
```

출력 원칙(`sales-psychology.md`와 연결):
- 헤드라인은 사양이 아니라 **고객의 순간**으로 시작한다.
- 효능, 수치, 후기는 **실제로 확인된 것만** 쓴다. 가짜 후기를 만들지 않는다. 자리만 표시한다.
- 건강기능식품이나 화장품은 과장 광고 표현("완치", "100% 효과")을 피한다.

### 예시 입력 (가상)
- 제품명: 데일리핏 그래놀라바 / 특징: 당 3g, 단백질 10g, 개별 포장 / 타겟: 아침을 거르는 2030 직장인 / 차별점: 당은 낮은데 바삭함 유지 / 변화: 출근길 한 손으로 든든한 아침 / 톤: 산뜻하고 건강한 느낌 / 문체: 설명형 존댓말 / 강조: 성분, 후기
