# 협찬·공구 제안하기 & 받은 제안 거르기

목표: **하루 1제안** 습관. 거절이나 무응답이 대부분이지만, 계속 연락한 사람은 기억에 남아 나중에 기회가 돌아온다.

## 4단계 프로세스

### 1. 제안할 아이템 정하기
- 내 계정 주제와 **직접 관련된** 아이템이 가장 좋고, 연관성이 있는 아이템도 괜찮다.
- 지금 올린 콘텐츠가 아니어도 "앞으로 올릴 수 있는" 아이템이면 리스트에 넣는다.
- 예시: 운동 계정 → 운동복 공구, 운동용품 / 여행 계정 → 숙소 협찬 / 육아 계정 → 육아용품

### 2. 제안할 업체 정하기
- 내가 써 본 곳, 이미 유명한 곳, 제품력이 좋은 곳을 **최대한 많이** 리스트로 만든다.
- 유명 브랜드일수록 답이 잘 오지 않지만, 그래도 보내서 나를 알리는 것 자체가 의미 있다.
- 업체를 찾다 보면 "체험단·크리에이터 모집" 공고를 발견하기도 한다. 이것도 바로 신청한다.

### 3. 제안 메일 & DM 보내기
- **메일과 DM을 둘 다** 보낸다. 업체마다 주로 확인하는 채널이 다르다.
- 연락처는 업체 홈페이지, 고객센터, 인스타 공식 계정 프로필에서 찾는다.
- **발송 기록표**를 꼭 관리한다. 열: 날짜 / 제안 종류 / 업체명 / 링크 / 연락 경로와 결과 / 인스타 ID / 홈페이지

### 4. 반응별 대응
- **무응답(사실상 거절)**: 꼭 하고 싶은 업체라면 전화로 메일을 확인했는지 묻고, 진행 가능한 최소 조건을 물어보며 적극적으로 어필한다.
- **긍정 회신**: 담당자 전화번호를 받아 **통화로** 빠르게 정리한다. 일정, 수수료, 필요한 자료를 미리 정리해 두고 물어본다. 내가 원하는 금액과 방향으로 이끄는 것이 목표다.

## 받은 제안 거르기

1. 팔로워가 늘면 공구·협찬 DM이 쌓인다. 팔로워가 아닌 사람의 DM은 **"요청" → "숨겨진 요청"** 폴더로 가니 주 3회 정도 확인한다.
2. 먼저 오는 제안은 브랜딩이 약하거나, 내 시간·에너지·비용을 고려하지 않고 싸게만 하려는 경우가 많다. 합리적인 제안인지 꼼꼼히 본다.
3. **내 가치 올리기**: 대부분 "무료"를 전제로 연락이 온다. 이럴 때는 내 단가 기준을 정해 두고 답장에 금액을 당당하게 제시한다. 받아들여지면 좋고, 거절당해도 "이 사람은 유료로 진행하는 사람"이라는 인식을 남긴다. 처음에는 무료로 시작해도 되지만, 특히 **릴스**처럼 제작 공수가 큰 콘텐츠는 적은 금액이라도 받는 것을 권한다.

## 출력 템플릿

### 아웃바운드 제안 메일
```
제목: [협업 제안] (계정 주제) 크리에이터 (이름) – (브랜드명) (제품) 콘텐츠 제안

안녕하세요, (브랜드명) 담당자님.
(주제) 콘텐츠를 만드는 (이름)입니다. (팔로워 수 / 평균 조회수 / 타겟층 한 줄)

(브랜드/제품)을 (써 본 경험 또는 관심 이유)로 눈여겨보고 있었고,
제 팔로워인 (타겟) 분들께 (구체적인 콘텐츠 아이디어 1~2개)로 소개하고 싶어 연락드렸습니다.

- 제안 형태: (협찬 리뷰 / 공동구매 / 유료 광고)
- 예상 콘텐츠: (릴스 1편 + 스토리 2회 등)
- 참고 콘텐츠: (링크)

편하신 방식으로 회신 주시면 자세히 논의하고 싶습니다.
감사합니다.
(이름) / (연락처) / (인스타 ID)
```

### 무료 협찬 DM에 유료 단가로 답장하기
```
안녕하세요, (브랜드명) 담당자님 😊
협업 제안 주셔서 감사합니다!

저는 협업 콘텐츠를 단순 노출이 아니라 기획부터 함께 제작하고 있어서
현재 유료로만 진행하고 있습니다.

- 피드 게시물: 1건 (금액)
- 릴스: 1편 (금액)

진행 가능하시면 회신 부탁드립니다. 세부 내용은 맞춰서 논의드리겠습니다.
감사합니다!
```
단가는 사용자의 팔로워와 참여율에 맞춰 정하도록 함께 고민한다. 임의로 금액을 보장하지 않는다.
